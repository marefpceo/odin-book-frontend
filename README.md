## Getting Started

There are two (2) ways to access the project: 

1. **[Live Version][live-link]** for a general user experience.

2. **Local Installation** to install and run the project on a local machine. Proceed to the next section to verify prerequisites are met prior to installing. 

### Prerequisites

Verify that you have Node.js and NPM installed.

**Node:**

```sh
node -v (or --version)
```

*If not installed, download and installation procedures can be found at [Node.js][Nodejs-url] website.*

**NPM**

  ```sh
  npm -v (or --version)
  ```

*If not installed, download and installation procedures can be found at [NPM][NPM-url] website.*


### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/marefpceo/odin-book-frontend.git
   ```
2. Change directory to `odin-book-frontend`
   ```sh
   cd odin-book-frontend
   ```
3. Install NPM packages
   ```sh
   npm install
   ```
4. Start the dev server
   ```js
   npm run dev
   ```
5. Open your web browser and navigate to:
   ```sh
   http://localhost:5173/
   ```
